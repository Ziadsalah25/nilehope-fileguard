رحلة البيانات ببساطة

مثال: جهاز مسجل يرسل heartbeat، والمسؤول يفتح صفحة Devices.

Agent يقرأ إعداد الاتصال ويرسل طلبًا عبر HTTPS بمفتاح خاص بالجهاز.
agent_api.py يتحقق من المفتاح وصحة البيانات ويحدد سجل الجهاز.
db.py يحفظ heartbeat أو يقرأ معلومات الحالة من قاعدة البيانات.
واجهة React تطلب JSON عبر api.ts وتعرض النتيجة على الشاشة.

لا تخلط بين الأشياء: ظهور الجهاز يعني أن التسجيل والاتصال نجحا في وقت ما. هذا لا يعني أن الجهاز يمنع حذف الملفات.

ما الذي يفعله المشروع وما الذي لا يفعله؟

موجود بالكود

لوحة إدارة، تسجيل Agents، heartbeats، استقبال metadata وأحداث، سجل تدقيق، رفع اختياري مع موافقة، وعامل Recovery تجريبي منفصل.

ليس إنفاذًا للحذف

تسجيل حدث حذف لا يمنع Windows من الحذف. المنع الحقيقي يتطلب ضبط Share permissions وNTFS ACL على خادم الملفات.

ليس DLP شاملًا للأجهزة

التحكم المركزي في المتصفح وUSB وClipboard غير مكتمل في النسخة الحالية؛ هذه سياسات تحتاج Agent وإنفاذًا واختبارًا منفصلًا.

Recovery لا يساوي Backup إنتاجي

هو تجربة لاسترجاع بعد الحذف عند إعداد العامل والنسخة مسبقًا. التخزين المحلي القابل للمسح ليس نسخة مقاومة للفدية.

الحساب المشترك

إذا استخدم عدة أشخاص حساب Windows واحدًا، لا يمكن للتطبيق تمييز الشخص الحقيقي من اسم الحساب وحده.

المستندات تتغير

التقارير والخطط توثق حالة بتاريخها. راجع الكود والإعداد الفعلي قبل اعتماد أي خطوة نشر.

مسار تعلم للمبتدئ

ابدأ بـ README.md ثم docs/ARCHITECTURE.md لمعرفة الفكرة والحدود.
اقرأ services/management/app/__init__.py لتعرف كيف يبدأ Flask ويربط المسارات.
اقرأ schema.sql ثم db.py لفهم شكل البيانات وطرق تخزينها.
تتبع التسجيل في agent_api.py ثم قارنه بعميل Windows FileControlAgent.ps1.
تتبع صفحة من main.tsx إلى api.ts ثم console_api.py.
بعدها اقرأ RecoveryEngine.cs منفصلًا، لأنه عامل .NET مستقل عن لوحة React.
اختم بقراءة الاختبارات والوثائق. الاختبار يشرح السلوك المطلوب، لكنه لا يثبت ضبط بيئة الإنتاج.

فهرس الملفات: ابحث واشرح

الفهرس يحتوي كل 625 مسارًا من لقطة المشروع، بما فيها ملفات البناء والاعتمادات المترجمة. لكل اسم وصف مختصر. محتويات الأرشيفات ZIP غير مفكوكة وتظهر كل حزمة كملف واحد.

ملاحظة عن نطاق الفهرس

الفهرس يسرد ملفات المشروع المرئية وقت تجهيز الدليل. مجلدات SDK وكاشات Python وبيئات التطوير المحلية لا تمثل كود FileGuard وقد جُمعت في شرح حسب المجلد بدل سرد آلاف ملفات الاعتماد. ملف .env موضح دون قراءة أو عرض أي قيمة سرية. محتويات ZIP أرشيفات ساكنة وليست ملفات تشغيل نشطة.
